# Japan 2026

The trip guide and planner at https://hshringeri.github.io/japan-2026/. On a phone it runs like an app with three tabs: List, Map and Plan. Add it to your home screen from the share menu and it opens full screen and keeps working with a weak signal.

There's no build step. GitHub Pages serves the files as they are.

## Where things live

| File | What it holds |
| --- | --- |
| `data/places.json` | Every place in the guide: the original text, coordinates, area and tags |
| `data/trip.json` | The trip: stays, day by day plans, open questions |
| `data/guide.json` | The magazine's editorial text: cover, house rules, intros, tips, Gone notes, credits |
| `data/geo.json` | Geocoding results with their sources and notes |
| `data/hours.json` | Opening hours per place, generated by `tools/hours.py`; the app uses them to say open or closed in Japan time |
| `data/taxonomy.json` | Kinds (Shop, Eat, Music…) and which categories sit under each |
| `js/` | The app |
| `guide.css` | The original magazine styles, used by the Guide view |

The map is OpenFreeMap's colour Liberty style (OpenStreetMap data, no key) with labels switched to English and the style's own shop and food icons removed; `js/basemap.js` does both. Stays get their own badge on the map: pink for Airbnbs, black for hotels.

Pins say more the closer you zoom: the name from zoom 15, the name and tags from 17, and a card with a photo from 18. Where labels would overlap, a pin falls back to a smaller label or none. Tapping a pin zooms in and opens its card above it.

On a wide screen the list sits beside the map. The seam between them is draggable (drag, or focus it and use the arrow keys; double-click resets to 440px). The width is remembered per browser and ignored on phones, where the panel stays full width.

## Common edits

To add an Airbnb address, find the stay in `data/trip.json` and fill in `address`, `lat` and `lng`, then delete its `precisionNote`. Google Maps gives you the coordinates when you long-press a spot.

To change the plan, edit the `items` for that day in `data/trip.json`. A driving day can carry a `"route"` with a `title` and the Google Maps `url`; `python3 tools/route.py` then builds the road line through that day's stops into `data/routes.json`, which the map draws when that day is picked. An item with a `time` ("14:30") feeds the Now / Next card. `status` can be `"booked"` or `"tbd"`. Setting `"place": "<id>"` links an item to a guide place by its id from `data/places.json`.

To add a guide place, add it to `data/places.json` with `lat` and `lng`, then run `python3 tools/tag.py`. A place that wasn't in the original guide also gets `"source": "maps"` (or wherever it came from), so `tools/check.py` leaves it out of the byte-for-byte rebuild. Its cuisine goes in the `CUISINE` table in `tools/tag.py`.

## Tools

- `tools/check.py` proves no content from the original single-page guide was lost. It rebuilds every original entry byte for byte from the data. Run it before merging.
- `tools/extract.py` was the one-time split of the original page into data files.
- `tools/merge_geo.py` folds geocoding results into the places and assigns each one an area.
- `tools/tag.py` assigns kinds, cuisine, genre, shop style and practical flags.
- `tools/hours.py` builds `data/hours.json`, each place's opening hours, from the hours in its info line, with hand-checked entries in `tools/hours-manual.json` taking precedence. After editing either, run it with `--report` to see what didn't parse.
- `tools/route.py` fetches the driving line for each day with a `route` from the public OSRM router and writes `data/routes.json`. Run it after changing that day's stops.
- `tools/resize-images.sh` makes the app's copies of the photos.
- `tools/thumbs.py` makes the map cards' 300×180 photos in `img/thumbs/` from the per-place photos in commit bc0fa73, and writes `data/thumbs.json` with each one's credit.

To test locally, run `python3 -m http.server` in this folder and open http://localhost:8000. Adding `?now=2026-11-20T22:30` to the URL makes the app act as if it's that moment in Japan, and `?day=2026-11-24` opens on that trip day.
